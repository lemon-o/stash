# 重复项查重（Dupe Checker）

[重复短片查重工具](/sceneDuplicateChecker) 能够搜索您的收藏库，找出在视觉感知上高度相似的短片。这意味着两个文件即便码率、分辨率甚至片头片尾略有不同，也能被准确识别为同一内容。

为实现这一目标，Stash 需要为视频生成所谓的感知哈希值（pHash）。系统会从视频固定时间点提取 25 帧画面拼接为网格图，并使用 pHash 算法生成指纹。随后便可根据指纹距离比对找出数据库中相同或高度相似的视频。感知哈希可以在扫描期间生成，也可在“任务”页面单独批量生成。

> **⚠️ 注意：** 由于需要解码视频抽取帧，pHash 生成过程可能需要一定时间。

查重工具支持四种精度等级：
- `精确（Exact）`：仅查找 pHash 完全一致的短片。速度极快且极少误报。
- `高（High）` 与 `中（Medium）`：允许设定汉明距离范围内的近似值匹配，命中率高且误报率低。
- `低（Low）`：容许更大的差异，可能产生部分误报，但有助于找出经过大幅度重编码、裁切或加水印的重复视频。

> **⚠️ 注意：** 生成 pHash 要求视频文件完整未损坏。如果在采样截帧过程中遇到解码错误，Stash 将放弃生成该视频的 pHash，以避免产生错误指纹导致误匹配。

## 批量选择重复项

页面顶部的“选择选项...”下拉菜单提供了快捷的批量勾选策略。每种策略会自动选中每组重复视频中**除了保留文件以外**的所有其他副本，方便您快速复核并一键删除：

- **最大文件** 与 **最高分辨率**：保留体积最大或清晰度最高的版本，选中其余低画质副本。
- **最老 / 最新**：根据文件修改时间保留最老或最新鲜的版本。
- **首选编码格式**：优先保留符合所选目标编码（如 H.265/HEVC 或 AV1）的版本。
- **仅在编码一致时选择**：安全防护选项。勾选后，若一组重复文件中存在不同编码格式，则跳过不作自动选择，避免误删转码前的优质源文件。
