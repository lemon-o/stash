# 字幕支持

Stash 支持通过 SRT 和 VTT 文件提供外挂字幕。

只有当字幕文件与对应的短片视频文件位于同一文件夹中时，系统才会自动检测到它们。

请确保字幕文件的命名符合以下规范：

## 短片字幕命名

- `{短片文件名}.{语言代码}.{扩展名}`
- `{短片文件名}.{扩展名}`

其中 `{语言代码}` 为 [ISO-639-1](https://en.wikipedia.org/wiki/List_of_ISO_639-1_codes)（2个字母）标准代码（例如 `zh`、`en`），`{扩展名}` 为 `srt` 或 `vtt`。没有语言代码的字幕文件在播放器中会被标记为“未知”，但仍可正常播放使用。

包含字幕的短片可以使用“字幕”过滤条件进行筛选。

> **⚠️ 注意：** 如果字幕文件是在扫描之后新增的，您需要对该目录执行一次“选择性扫描”任务以更新识别。
