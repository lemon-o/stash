# 界面选项设置

## 语言环境

系统默认支持简体中文（zh-CN），切换语言会影响界面文字、数值格式化与日期展示。

## SFW 内容模式（工作安全模式）

SFW 模式用于声明所管理的内容为非成人内容。

启用该模式后，UI 将做如下自适应：
- 演员默认占位图替换为日常中性插画
- 隐藏与成人相关的敏感数据字段
- `O-Counter` 计数器更名为点赞喜爱数 `Like` 计数

## 预览墙媒体展示类型

短片墙和标记列表默认优先播放生成的视频切片预览（mp4）。您可以根据设备性能将其切换为 WebP 动图或静态封面。

> **⚠️ 注意：** 预览墙正常展示需要先在“任务”页面中生成相应的预览切片。

## 短片播放器配置

- **自动播放视频**：进入短片详情页时是否立即开始播放。
- **循环播放短视频**：支持为低于指定时长的短视频开启自动循环（设为 0 表示禁用）。
- **播放历史与进度记忆（Track Activity）**：开启后记录短片播放次数与累计播放时长，未播完时保存断点进度，下次播放时自动从上次离开的位置继续。
- **最小播放有效判定比率**：观看超过该比例后才计入一次有效播放次数。

## 自定义外观与扩展（CSS / JavaScript）

Stash 允许注入自定义 CSS 样式表与 JavaScript 脚本，以便随心深度定制专属主题与交互动效。
