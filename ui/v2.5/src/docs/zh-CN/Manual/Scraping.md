# 元数据刮削（Scraping）

Stash 支持从各种外部网站与数据源刮削提取元数据。

## 刮削器类型

| 类型 | 说明 |
|---|:---|
| 片段（Fragment） | 利用本地已有的元数据（如时长、哈希或标题切片）在远端数据源中进行特征比对。 |
| 关键词搜索（Search/By Name） | 使用用户输入的查询词检索外部数据源，返回候选项列表供选择。 |
| URL 网址抓取 | 直接从指定的网页 URL 中解析并提取详情元数据。 |

## 管理与安装刮削器

刮削器可在 `设置 > 元数据提供商（Metadata Providers）` 页面中进行安装、更新与统一管理。

系统已默认配置了官方社区稳定的刮削器包源 `Community (stable)`，您可以浏览丰富的站点刮削器，一键安装或升级。
