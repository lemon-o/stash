# 元数据识别（Identify）

“识别”任务会依次遍历您的短片，并尝试通过所选的刮削来源（Scraper sources）对短片进行自动识别。如果在某个数据源中找到了匹配结果，该短片就会被更新，并且后续的数据源将不再对该短片进行重复比对。

此任务属于高级设置模式。

## 识别规则

- 本任务支持添加一个或多个刮削数据源，包括 stash-box 实例以及支持按视频特征切片刮削的刮削器。可以自由拖动排列数据源的优先级次序。
- 任务将严格按照配置好的数据源顺序依次尝试匹配。
- 一旦在某个数据源找到了唯一匹配，短片数据即被写入，后续数据源不再处理该短片。

### “已整理（Organized）”状态标记

被标记为“已整理（Organized）”的短片在执行“识别”任务时会自动跳过，避免覆写已人工精细整理过的信息。您也可以通过过滤器根据该状态进行精确筛选。

## 选项配置

| 选项 | 说明 |
|------|------|
| 演员性别筛选 | 过滤在识别过程中需要导入的演员性别。若不选择，则默认导入所有性别的演员。 |
| 设置封面海报 | 若取消勾选，则识别时不会修改短片原有的封面图。 |
| 设置已整理标记 | 若启用，短片在成功识别后会自动被标记为“已整理”。 |
| 跳过包含多个候选项的匹配 | 若未启用且刮削返回了多个可能匹配，系统会随机挑选一个；启用后会跳过歧义项，等待人工确认。 |
| 为跳过的匹配添加标签 | 与上述选项配合使用，为跳过的短片打上特定标签，以便在“短片打标器”中集中筛选和人工精准匹配。 |
| 跳过无消歧信息的单名演员 | 避免误匹配通用单名演员（如 Samantha 等常见英文名）。 |
| 为跳过的演员添加标签 | 为包含跳过演员的短片打上标签，便于后续人工审核。 |

### 字段级策略选项

每个数据字段均可自定义合并策略：

| 策略 | 说明 |
|------|------|
| 忽略（Ignore） | 不设置该字段。 |
| 覆盖（Overwrite） | 强制用刮削到的新数据覆盖已有数据。 |
| 合并（Merge，默认） | 对于多值字段（如标签、演员），将新数据追加到已有列表；对于单值字段，仅在当前为空时写入。 |

对于工作室、演员和标签，还提供“**创建暂无的对象**”选项（默认开启）。开启时，若抓取到的演员/工作室/标签在本地库中不存在，系统将自动创建对应实体。

## 执行任务

- **识别...：** 从“任务”页面对全媒体库执行识别任务。
- **选择性识别：** 从“任务 > 识别...”页面点击顶部文件夹图标，指定特定目录执行识别。

## 运行日志

每个短片的识别匹配详细过程均会实时输出在日志中，便于随时查看。
