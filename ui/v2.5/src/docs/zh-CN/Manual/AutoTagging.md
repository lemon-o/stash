# 自动打标签（Auto Tag）

“自动打标签”功能会根据文件路径或文件名中包含的名称，自动为您的媒体分配演员、工作室和标签。该任务适用于短片、图片和图库相册。

此任务属于高级设置模式。

## 匹配规则

> **⚠️ 重要提示：** 自动打标签仅会匹配您 Stash 数据库中**已经存在**的实体名称，它不会凭空创建新的演员、工作室或标签。

- 多词名称在按顺序出现且被以下分隔符隔开时会被匹配：英文句点 `.`、连字符 `-`、下划线 `_` 或空白字符。这些分隔符被视为词边界。
- 匹配不区分大小写，但要求必须在词边界内完全匹配完整词汇，部分单词或拼写错误不会被匹配。
- 自动打标签不会匹配演员的别名（Aliases）。

### 匹配示例（以演员“Jane Doe”为例）

**成功匹配的情况：**

| 文件名示例 | 说明 |
|---|---|
| `Jane.Doe.1.mp4` | 句点作为单词分隔符。 |
| `Jane_Doe.2.mp4` | 下划线作为单词分隔符。 |
| `Jane-Doe.3.mp4` | 连字符作为单词分隔符。 |
| `Jane Doe.4.mp4` | 空格作为单词分隔符。 |
| `Mary-Jane-Doe` | 词边界外存在额外单词依然允许匹配。 |
| `Jane-Doe_n` | 词边界外存在额外字符允许匹配。 |
| `[OF]jane doe` | 包含方括号前缀允许匹配。 |

**无法匹配的情况：**

| 文件名示例 | 说明 |
|---|---|
| `Maryjane-Doe` | 多个词连在一起，缺少有效分隔符。 |
| `Jane-Doen` | 拼写不符。 |

### “已整理（Organized）”状态标记

被添加“已整理”标记的短片、图片和图库相册不会被自动打标签任务修改。您也可以用“已整理”状态进行筛选。

工作室实体同样支持“已整理”标记，但其仅用作信息展示，代表用户认为该工作室的归档已完备，并不影响自动打标签的逻辑。若要彻底排除某个工作室，应使用“忽略自动打标签”属性。

### “忽略自动打标签”属性

被设置了“忽略自动打标签”属性的演员或标签，在执行自动打标签任务时会被自动忽略。

## 执行任务

- **自动打标签：** 可在“任务”页面对全库运行自动打标签。
- **选择性自动打标签：** 可在“任务”页面针对特定目录执行自动打标签。
- **单独页面触发：** 可以在具体的演员、工作室或标签详情页中单独触发针对该对象的打标签任务。

### 关闭确认警告提示

在运行自动打标签任务前默认会弹出二次确认对话框。如果您频繁使用该功能，可在弹窗中勾选“不再显示此警告”，或在 `设置 > 任务 > 自动打标签 > 禁用自动打标签警告` 中关闭。
