# 快捷键列表

## 全局快捷键

| 快捷键 | 动作 |
|--------|------|
| `?` | 打开帮助与手册 |

### 全局页面导航

| 快捷键 | 目标页面 |
|--------|----------|
| `g s` | 短片列表（Scenes） |
| `g i` | 图片列表（Images） |
| `g v` | 集合列表（Groups） |
| `g k` | 标记列表（Markers） |
| `g l` | 图库列表（Galleries） |
| `g p` | 演员列表（Performers） |
| `g u` | 工作室列表（Studios） |
| `g t` | 标签列表（Tags） |
| `g z` | 系统设置（Settings） |

## 列表查询页面快捷键

| 快捷键 | 动作 |
|--------|------|
| `/` | 聚焦搜索框 / 聚焦筛选对话框的查询框 |
| `f` | 打开添加筛选条件对话框 |
| `r` | 随机排序模式下重新洗牌打乱 |
| `v g` | 切换视图为网格（Grid） |
| `v l` | 切换视图为列表（List） |
| `v w` | 切换视图为预览墙（Wall） |
| `v t` | 切换视图为打标器（Tagger） |
| `+` | 放大缩放滑块 |
| `-` | 缩小缩放滑块 |
| `←` | 上一页 |
| `→` | 下一页 |
| `Shift + ←` | 前翻 10 页 |
| `Shift + →` | 后翻 10 页 |
| `Ctrl + Home` | 跳转到第一页 |
| `Ctrl + End` | 跳转到最后一页 |
| `s a` | 全选当前页 |
| `s n` | 取消全选 |
| `s i` | 反向选择 |
| `e` | 批量编辑选中项 |
| `d d` | 批量删除选中项 |

## 短片主列表快捷键

| 快捷键 | 动作 |
|--------|------|
| `p r` | 随机播放短片 |

## 短片详情与播放页面快捷键

| 快捷键 | 动作 |
|--------|------|
| `a` | 切换至详情标签页 |
| `q` | 切换至播放队列标签页 |
| `k` | 切换至标记标签页 |
| `i` | 切换至文件信息标签页 |
| `e` | 切换至编辑标签页 |
| `h` | 切换至历史记录标签页 |
| `,` | 显示/隐藏侧边栏 |
| `.` | 显示/隐藏时间轴缩略图条 |
| `o` | 增加 O-Counter 计数 |
| `d d` | 删除当前短片 |
| **评分** ||
| `r {1-5}` | 设置星级评分（1-5 星） |
| `r 0` | 清除星级评分 |
| `r {0-9} {0-9}` | 设置十分制评分（例如 `00` 为 10.0 分） |
| ``r ` `` | 清除十分制评分 |
| **封面生成** ||
| `c c` | 使用当前播放画面生成封面截图 |
| `c d` | 生成默认截图封面 |
| **播放控制** ||
| `p n` | 播放队列中的下一个短片 |
| `p p` | 播放队列中的上一个短片 |
| `p r` | 随机播放队列中的短片 |
| `空格（Space）` | 播放 / 暂停 |
| `回车（Enter）` | 播放 / 暂停 |
| `←` | 快退 10 秒 |
| `→` | 快进 10 秒 |
| `Shift + ←` | 快退 5 秒 |
| `Shift + →` | 快进 5 秒 |
| `Ctrl/Alt + ←` | 快退 1 分钟 |
| `Ctrl/Alt + →` | 快进 1 分钟 |
| `{1-9}` | 跳转到总时长的 10%-90% |
| `[` | 往回跳转 10% 时长 |
| `]` | 往前跳转 10% 时长 |
| `↑` | 音量增加 10% |
| `↓` | 音量减少 10% |
| `m` | 静音 / 取消静音切换 |
| `l` | A/B 片段循环切换（按一次设置起点，再按一次设置终点，第三次退出循环） |
| `Shift + l` | 切换播放结束时是否单片循环 |
