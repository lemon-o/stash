# 短片文件名解析器

[文件名解析工具](/sceneFilenameParser) 能够分析您媒体库中的短片文件名，并提取规则将其批量填入元数据。

## 解析匹配规则

使用该工具时需输入匹配表达式模式（Pattern），支持使用以下占位字段：

| 字段 | 说明 |
|------|------|
| `title` | 捕获其中的文本并设置为短片标题。 |
| `ext` | 匹配文件名末尾的扩展名（不捕获，不包含最后一个 `.`）。 |
| `d` | 匹配常见分隔符（`-_.`），不捕获。 |
| `i` | 匹配“忽略词”输入框中填写的任意忽略词（以空格分隔），不捕获。适合过滤类似 `DVDRip`、压制组名称等干扰词。 |
| `date` | 匹配 `yyyy-mm-dd` 格式日期并设为短片发布日期。 |
| `rating` | 匹配单数字并设为评分。 |
| `performer` | 根据捕获文本匹配并添加演员。 |
| `tag` | 根据捕获文本匹配并添加标签。 |
| `studio` | 根据捕获文本匹配并关联工作室。 |
| `{}` | 匹配任意字符，不捕获。 |

> **⚠️ 注意：** `performer`、`tag` 和 `studio` 字段只会匹配本地系统中已经存在的实体。

系统在查询前会自动去除捕获词前后的分隔符（`.-_`），名称匹配不区分大小写。

同时还支持以下细分日期组件字段：

| 字段 | 说明 |
|------|------|
| `yyyy` | 4位数字年份 |
| `yy` | 2位数字年份（默认前两位为 `20`） |
| `mm` | 2位数字月份 |
| `mmm` | 英文月份缩写，例如 `Jan`（不区分大小写） |
| `dd` | 2位数字日期 |

此外还支持完整紧凑日期格式：`yyyymmdd`、`yymmdd`、`ddmmyyyy`、`ddmmyy`、`mmddyyyy`、`mmddyy`。可通过界面的“添加字段”按钮快速插入。

标题生成选项：

| 选项 | 说明 |
|------|------|
| 空白字符替代 | 将这些字符替换为空格（默认为 `._`，用于处理 `three.word.title.mp4` 这类文件名） |
| 标题单词首字母大写 | 将标题中每个单词的首字母转换为大写 |

可在“显示字段”下拉菜单中选择需要在结果中展示的列。

## 应用解析结果

设定好模式后，点击“查找”按钮。系统将检索符合模式的短片。

匹配结果将展示在表格中，直观列出当前值与即将更新的值，并通过复选框控制每个字段是否生效。您也可以直接在表格中微调修改。确认无误后点击“设置全部”即可批量应用。
