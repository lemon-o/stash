# 参与贡献

## 财务赞助

我们非常欢迎并感谢赞助支持，您可以通过 [Open Collective](https://opencollective.com/stashapp) 或 [GitHub Sponsors](https://github.com/sponsors/stashapp) 支持开源作者。

## 代码开发

Stash 后端使用 Go 语言开发，采用 SQLite 数据库。前端界面使用 TypeScript + React 构建。非常欢迎贡献漏洞修复、性能优化以及新功能！请参阅官方代码库中的 `DEVELOPMENT.md` 获取开发起步指南。也可以在 [Discord](https://discord.gg/2TsNFKt) 交流协助。

## 文档建设

完善 Stash 的文档不仅能够帮助广大新用户快速上手，还能有效降低社区答疑成本。欢迎通过提交 GitHub Pull Request，或在 [GitHub Issues](https://github.com/stashapp/stash/issues) 与 [Discord](https://discord.gg/2TsNFKt) 提交改进建议。

## 功能测试与反馈

我们非常欢迎社区用户参与新版本与修复补丁的测试反馈。
每个 Pull Request 在 GitHub 上均会自动通过 GitHub Actions 编译 Linux、Windows 和 macOS 的测试二进制程序，可在对应 PR 的 Checks -> Artifacts 中下载体验。

## 提交 Bug 与功能建议

如果您发现了缺陷或有好的改进点子，欢迎在 [GitHub Issues](https://github.com/stashapp/stash/issues) 中向社区反馈。
