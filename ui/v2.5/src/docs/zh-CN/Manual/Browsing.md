# 内容浏览与筛选

## 搜索与查询

### 关键词搜索

顶部文本搜索框允许您输入关键词进行全库检索。不同对象类型检索的字段范围如下：

| 对象类型 | 搜索的字段 |
|----------|------------|
| 短片（Scene） | 标题、简介详情、文件路径、OSHash、校验码、标记标题 |
| 图片（Image） | 标题、简介详情、文件路径、校验码 |
| 集合（Group） | 标题 |
| 标记（Marker） | 标题、短片标题 |
| 图库（Gallery）| 标题、文件路径、校验码 |
| 演员（Performer） | 姓名、别名 |
| 工作室（Studio） | 名称、别名 |
| 标签（Tag） | 名称、别名 |

### 搜索语法规则

- 默认情况下，多个关键词为“与”关系，要求必须在同一个字段中同时出现。
- 使用 `or` 或管道符 `|` 进行“或”逻辑匹配（命中任一词即可）。
- 使用减号 `-` 排除特定词汇。
- 使用双引号 `"` 精确匹配完整短语。
- 搜索不区分英文大小写。

#### 语法示例

| 搜索输入 | 说明 |
|---|---|
| `foo bar` | 同时包含 `foo` 和 `bar`。 |
| `foo or bar` 或 `foo | bar` | 包含 `foo` 或 `bar` 其一。 |
| `foo -bar` | 包含 `foo` 但排除包含 `bar` 的内容。 |
| `"foo bar"` | 精确匹配完整词组 `"foo bar"`。 |

### 过滤器

点击搜索框右侧的漏斗过滤器图标，可以添加多维度的复合过滤条件（例如：评分、日期区间、演员、标签、分辨率等）。

每个条件类型支持多种修饰符，例如“包含”、“排除”、“为空”、“正则表达式匹配”等。
