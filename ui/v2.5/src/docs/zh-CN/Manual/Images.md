# 图片与图库

图片（Images）既可以作为独立媒体被扫描，也可以汇集成图库画册（Galleries）。将一组图片组织为图库有以下四种方式：

1. 将它们存放在同一个文件夹中，并在媒体库设置中启用 **从包含图片的文件夹创建图库** 选项。图库名称将自动使用文件夹名称。
2. 将它们存放在同一个文件夹中，并在该文件夹下创建一个名为 `.forcegallery` 的空标记文件。
3. 将一组图片打包为一个 `.zip` 压缩包。图库名称将采用该 zip 文件的名称。
4. 在 Stash 界面中的“图库”页面点击“新建”，然后手动将图片关联添加进去。

在图库详情页面中可以随时手动添加或移除图片。

建议在制作图库 zip 文件时使用“仅存储/无压缩（Store / No Compression）”模式（例如 Linux 下使用 `zip -0 -r gallery.zip folder/`）。由于解压图片需要高频随机读取，无压缩模式能**大幅提升**浏览响应速度与性能。

如果图库 zip 包内存在以 `cover.jpg` 结尾的文件，它会被优先提取用作图库的封面海报。您也可以在图库详情页中选中任意图片，点击右上角 ⋯ 菜单并选择“设为封面”。

## 短视频动图与短切片（Image Clips / GIFs）

图片列表中同样支持展示短视频片段或动图（GIF / 短视频循环切片）。若要将特定视频文件按图片类型导入：
- 可以在媒体库配置中开启 **将视频扩展名作为图片短切片扫描** 选项。
- 或者将相应文件后缀从“视频扩展名”移至“图片扩展名”列表中。

在“任务”页面中勾选“为图像短片生成预览图”，可以为其生成动态缩略图。

## 按演员拍摄时年龄排序

图片列表支持按 **演员拍摄时年龄（Performer Age）** 进行排序。系统会比对图片的拍摄日期与演员的出生年月日计算得出年龄。
