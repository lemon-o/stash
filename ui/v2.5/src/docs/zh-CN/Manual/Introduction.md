# 入门介绍

Stash 通过读取您提供的路径来为您的多媒体文件建立索引与分类。在您[配置](/settings?tab=library)好媒体存储的目录后，只需在 [`设置 -> 任务`](/settings?tab=tasks) 页面中点击“扫描”按钮，Stash 就会开始将您的媒体内容扫描并导入到媒体库中。

为了获得最佳浏览体验，建议在扫描完成后生成视频预览与时间轴精灵图。您可以在 [`设置 -> 任务`](/settings?tab=tasks) 页面中执行此操作。

> **⚠️ 注意：** 目前系统同一时间只支持执行一个任务。不过系统支持任务队列，您可以将生成任务加入队列，在扫描任务完成后自动无缝执行。

当媒体导入完毕后，您就可以开始创建演员、工作室与标签，对您的私密收藏进行深度整理与鉴赏了！
