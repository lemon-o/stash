# 短片打标器（Scene Tagger）

Stash 支持与 stash-box 社区中心元数据服务深度集成，可基于文件指纹或关键词检索，实现短片与演员元数据的批量精准打标。批量打标界面可通过 [短片打标视图](/scenes?disp=3) 进入。

## 检索匹配

指纹检索将为您选中的文件与远程 stash-box 服务进行数字指纹比对。命中指纹的短片将直接展示匹配结果，建议在批量保存前复核确认。

如果未找到指纹匹配，系统支持通过关键词进行文本搜索。查询会比对短片的**标题**、**发布日期**、**工作室名称**及**演员姓名**。

需要注意的是，检索要求**所有查询词均需命中**。例如短片标题为 `"A Trip to the Mall"`，演员为 `"Jane Doe"`，若搜索 `"Trip to the Mall 1080p"` 则**无法**命中（因为存在干扰词 1080p），但搜索 `"trip mall doe"` 可以精准命中。通常输入演员姓名+发布年份或工作室即可快速定位。可在配置中将常见无用后缀加入黑名单，系统会在搜索时自动剔除。

## 保存与关联

匹配到短片后，Stash 会尝试将远程的工作室和演员与本地数据库已有实体进行关联。若此前已关联过，系统会自动勾选；若未曾关联，您可以从下拉列表中选择匹配的本地实体、点击创建全新实体或选择跳过。

短片保存后，对应的 `stash_id` 会被保存在数据库中，供未来的打标与同步使用。

## 提交指纹贡献

在短片打标保存后，系统会提示是否将此文件的指纹回传至远程 stash-box 实例。这是完全可选的贡献行为，能帮助社区中拥有相同副本的其他用户直接通过指纹秒级匹配。Stash 仅回传 `stash_id` 与经过哈希的算法指纹，不包含任何私人隐私数据。
