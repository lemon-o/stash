# 任务管理

此页面允许您指示 Stash 服务器执行各种后台任务。

## 扫描

扫描功能会遍历您配置的媒体目录，查找新增和移动的文件。

Stash 目前通过执行快速文件哈希（quick file hash）来识别文件。这意味着，如果文件在您配置的 Stash 目录内被重命名或移动到其他位置，扫描将检测到此变更并相应更新数据库。

Stash 目前会忽略重复文件。如果两个文件内容完全相同，则只会使用首先检测到的文件。

### 使用 `.stashignore` 忽略文件

您可以创建 `.stashignore` 文件以排除扫描特定文件或目录。这些文件使用与 `.gitignore` 相同的匹配语法。

将 `.stashignore` 文件放置在媒体库中的任意目录下，该文件中的规则将应用于该目录及其所有子目录中的文件。您可以在目录结构的不同层级放置多个 `.stashignore` 文件——父目录的规则会级联应用到子目录。

`.stashignore` 文件不会在 zip 压缩包内部被读取。

**支持的匹配规则：**

| 规则 | 说明 |
|------|------|
| `filename.mp4` | 忽略特定文件。 |
| `*.tmp` | 忽略具有特定扩展名的所有文件。 |
| `temp/` | 忽略目录及其所有内容。 |
| `**/cache/` | 忽略任何层级中名为 "cache" 的目录。 |
| `!important.mp4` | 排除取反——即使匹配了先前的忽略规则，也不忽略此文件。 |
| `# 备注` | 以 # 开头的行为注释。 |
| `\#filename` | 使用反斜杠转义以匹配字面字符 #。 |

**示例 `.stashignore` 文件：**

```
# 忽略临时文件
*.tmp
*.log

# 忽略特定目录
temp/
.thumbnails/

# 但保留该特定文件
!important.tmp
```

扫描任务支持以下选项：

| 选项 | 说明 |
|------|------|
| 生成短片封面 | 为视频文件生成封面海报图。 |
| 生成预览 | 生成鼠标悬停在短片上时播放的视频预览（mp4）。 |
| 生成动态图片预览 | *高级模式下可用* - 同时生成动态图片（webp）预览，仅当短片/标记墙的预览类型设置为动态图片时需要。浏览时相比视频预览占用更少 CPU，但这是额外生成的较大文件。|
| 生成时间轴预览小图 | 生成视频播放器下方用于快速时间轴拖拽定位的精细预览图集（Sprites）。 |
| 生成视频感知哈希值 | 生成感知哈希（pHash），用于短片查重和特征识别。 |
| 生成图片的缩略图 | 为图片文件生成缩略图。 |
| 生成图像感知哈希值 | 生成图片感知哈希，用于图片查重与识别。 |
| 为图像短片生成预览图 | 为动图/图像短片生成 gif/循环视频作为缩略图预览。 |
| 重新扫描文件 | 默认情况下，Stash 仅在文件修改时间自上次扫描后发生变化时才重新扫描。启用此选项后，Stash 将重新扫描路径中的所有文件，无论其修改时间如何。仅在需要重新计算视频/图片元数据或重新扫描图库 zip 时需要。 |

## 生成内容

生成内容功能提供以下媒体资源：

* 短片封面 - 用作封面图片的短片画面截图
* 视频或动态图片预览 - 鼠标悬停在短片卡片上时播放的动态切片
* 视频感知哈希（pHash） - 协助匹配 StashDB 并为重复项查找提供数据
* 时间轴预览精灵图（Sprites） - 在播放器进度条上方展示的画面缩略图
* 标记视频预览 - 在标记页面中展示的视频片段预览
* 视频转码版本 - 详见下文
* 图库相册缩略图
* 图像感知哈希 - 可用于图片识别和去重

生成任务支持以下选项：

| 选项 | 说明 |
|------|------|
| 短片封面 | 为视频文件生成短片封面海报。 |
| 预览 | 生成视频预览切片（mp4），鼠标悬停在短片上时自动播放。 |
| 动态图片预览 | *高级模式下可用* - 生成动态预览图（webp）。仅在预览类型设为动态图片时需要，且需要先启用“预览”。 |
| 短视频时间轴预览的小图 | 生成用于播放器时间轴定位的预览精灵图（Sprites）。 |
| 标记预览 | 生成从标记时间点开始的视频切片（mp4）。有明确结束时间的标记将截取该区间（受“标记预览最大时长”限制）；未指定结束时间的标记使用“默认标记预览时长”（默认为 20 秒）。两者均可在 `设置 → 系统 → 预览生成` 中配置。 |
| 标记动态图片预览 | *高级模式下可用* - 同时为标记生成动态预览图（webp），仅在标记预览类型设置为动态图片时需要。 |
| 标记的屏幕截图 | 为标记生成静态 JPG 截图。仅在预览类型设置为静态图片时需要，需先启用“标记预览”。 |
| 转码 | *高级模式下可用* - 将不支持的视频格式转换为 MP4 格式，以便直接串流而无需实时转码。 |
| 视频感知哈希值 | 生成感知哈希值，用于短片甄别和重复检测。 |
| 产生热图和速度资料给有互动的短片 | 为交互设备支持的短片生成热图和速度数据。 |
| 图像片段预览 | 为动图/短片段生成循环视频/缩略图。 |
| 图像缩略图 | 为图片文件生成缩略图。 |
| 图像感知哈希值 | 生成图片感知哈希，用于图片去重和识别。 |
| 覆盖现有文件 | 默认情况下，已生成的文件不会重新生成。勾选此项将强制重新生成所有文件。 |

### 转码

Web 浏览器支持的音视频编解码器和容器格式有限。当浏览器支持时，Stash 会直接串流视频文件。最初 Stash 无法播放浏览器原生不支持的格式，因此通过预先生成转码文件来支持播放。

现在 Stash 已经支持实时动态转码（Live Transcoding），因此预先转码在绝大多数情况下已无必要。此外，转码会消耗大量的磁盘空间，且不保证无损。

### 相册/图库缩略图

这些缩略图是在首次查看图库时自动生成的，因此通常不需要预先批量生成。

## 清理

此任务会遍历您配置的媒体目录，并从数据库中移除所有已不存在的短片记录。它还会清理已被删除短片对应的生成文件。

执行此任务时请务必谨慎，特别是在网络存储或挂载目录可能因网络波动暂时无法访问的情况下。

## 导出与导入

导入和导出任务支持将元数据以 JSON 文件形式读写到配置的元数据目录。从文件导入会将数据合并到当前数据库中。

> **⚠️ 注意：** 完整导入（Full import）任务会在导入前**完全清空**当前数据库！

关于导出 JSON 的格式规范，请参阅 [JSON 规范](/help/JSONSpec.md) 页面。

## 备份

备份任务会为 Stash 数据库和 Blob 文件（可选）创建备份。备份文件可以直接下载，也可以输出到备份目录（位于 `设置 > 路径`）或数据库目录（如果未配置备份目录）。

对于完整备份，必须同时复制数据库文件和所有 Blob 文件。备份将保存为 zip 文件，数据库文件位于 zip 根目录，Blob 文件位于 `blobs` 子目录。

> **⚠️ 注意：** 生成的文件（预览、缩略图等）不包含在备份中，因此从备份恢复到空系统时需要重新生成这些辅助文件。

对于仅数据库备份，只会备份数据库文件。这对于在进行风险操作前做快速备份非常有用，也适用于未使用文件系统 Blob 存储的用户。

## 从备份恢复

从备份恢复目前为手动操作过程：将备份 zip 解压，把数据库文件和 Blob 文件（若有）分别复制回对应的数据库目录和 Blob 目录中，然后重启 Stash 即可加载恢复的数据。

> **⚠️ 注意：** 仅数据库备份的文件名与原始数据库文件名不同，复制前需先将备份的数据库文件重命名为原始文件名。您可在 `设置 > 路径 > 数据库路径` 中查看原始数据库文件名。
