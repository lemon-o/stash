# 系统配置（Configuration）

## 媒体库（Library）

在此区域中，您可以添加或移除由 Stash 索引的媒体目录。添加的目录将用于扫描新文件以及在文件发生移动时自动更新数据库定位。

您可以针对每个目录单独指定其包含的内容类型：
- **视频**
- **图片**
- **两者皆包含**

> **⚠️ 注意：** 修改或添加目录后，请务必点击“保存”使配置生效！

## 排除正则匹配规则（Excluded Patterns）

您可以输入有效的正则表达式（Regex），与模式匹配的文件或文件夹将在扫描过程中被跳过，不会写入数据库。
在执行清理任务时，如果数据库中存在命中了排除规则的条目，该条目及其生成文件也会被移除。

匹配规则不区分大小写。视频与图片/图库分别拥有独立的排除配置项。

常见规则示例：
- `"sample\.mp4$"` 排除所有以 sample.mp4 结尾的短样片
- `"/\.[[:word:]]+/"` 排除以点开头的隐藏文件夹
- `"c:\\stash\\videos\\exclude"` 排除特定 Windows 文件夹

## 从文件夹创建图库

开启“从包含图片的文件夹创建图库”后，系统会自动为每个含有图片的文件夹创建图库相册。
若希望对单个目录进行特例控制，可在对应文件夹内放置空标记文件：
- 放置 `.nogallery`：即使全局开启，也强制不将该目录作为图库导入
- 放置 `.forcegallery`：即使全局未开启，也强制将其作为图库导入

## 文件哈希算法

Stash 采用哈希算法作为视频文件的唯一标识，支持 `oshash` 与 `MD5` 两种算法：
- `oshash`（OpenSubtitles 算法）：仅读取视频文件头尾各 64KB，计算极快，尤其适合局域网 NAS 共享存储。
- `MD5`：需完整遍历整个文件，耗时较长。系统默认推荐使用 `oshash`。

生成的封面切片、预览视频与精灵图等辅助文件均基于所选哈希值进行命名和索引。
