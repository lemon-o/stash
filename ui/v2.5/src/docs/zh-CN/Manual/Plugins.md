# 插件系统（Plugins）

Stash 拥有功能强大的插件架构，支持：
- 从“任务”页面由用户手动触发自定义插件任务
- 监听系统事件（如扫描完成、短片新建等）自动执行钩子任务
- 为前端 UI 注入自定义 CSS 样式
- 为前端 UI 注入自定义 JavaScript 脚本与交互组件

插件任务支持通过内置 JavaScript（Goja 引擎）或调用外部独立程序（如 Python、Shell 或可执行文件）来执行。

## 安装与管理插件

插件可在 `设置 > 插件（Plugins）` 页面进行可视化安装与管理。

系统默认配置了官方社区插件包源 `Community (stable)`。安装好的插件可以一键启用、禁用、升级或卸载。

## 手动添加本地插件

Stash 默认在 `config.yml` 所在目录下的 `plugins` 子文件夹寻找插件。
在 `plugins` 文件夹下放置插件目录及对应的 `pluginName.yml` 清单配置文件即可。
修改后在设置页面点击“重新加载插件”即可实时生效。
